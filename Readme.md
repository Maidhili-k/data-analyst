# Cognifyz Technologies – Data Analysis Internship
# Restaurant Data Analysis Using Python

## Project Overview

This project analyzes restaurant data to understand cuisines, restaurant ratings, price ranges, online delivery, geographical distribution, and restaurant chains.

## Dataset

The project uses the DatasetC CSV file containing restaurant information.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Tasks

### Level 1

1. Top Cuisines
2. City Analysis
3. Price Range Distribution
4. Online Delivery

### Level 2

1. Restaurant Ratings
2. Cuisine Combination
3. Geographic Analysis
4. Restaurant Chains

## Project Files

1. DatasetC .csv: Input dataset
2. Restaurant_Data_Analysis.ipynb: Python code, analysis, and results
3. outputs/: Generated charts and visualizations

## Project Outputs

Charts and visualizations generated by Python will be saved in the outputs folder.

## Conclusion

The project uses exploratory data analysis and data visualization to understand restaurant-related trends and patterns.
